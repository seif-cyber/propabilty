# مذاكرة الاحتمالات BSM214

تطبيق ويب للمذاكرة (PWA) بيشتغل من غير نت بعد أول فتحة: شرح المحاضرات، أسئلة الميد القديمة محلولة، بنك أسئلة، غلطاتي، جدول Z و t، ودليل الآلة الحاسبة fx-991.

## التشغيل على الموبايل (GitHub Pages)
1. Settings ← Pages ← Source: **Deploy from a branch** ← Branch: `main` / `(root)` ← Save.
2. بعد دقيقة هيظهر الرابط: `https://<username>.github.io/<repo>/`
3. افتحه من Chrome على الموبايل ← القايمة (⋮) ← **Add to Home screen / Install app**.

## التشغيل على الكمبيوتر
افتح `index.html` مباشرة، أو شغّل `تشغيل التطبيق.bat`.

## لو عدّلت حاجة
غيّر رقم `CACHE` في `sw.js` عشان الموبايل ياخد النسخة الجديدة.
